# 知隙需求规格说明书 V0.1

项目类型：课程作业。产品形态：Windows 桌面应用＋共享云端提醒服务。目标用户：开发者本人及少量朋友。需求日期：2026-10-22。

## 一、产品定位与总体目标

知隙面向技术学习与面试准备，用户选择主题后，通过问答与追问发现理解问题，生成学习总结，记录个人学习状态，通过变式复测检查掌握情况，后续扩展到通用学习。

核心能力包括：Agent 在授权本地目录读写 Markdown；对话及总结导出 PDF、Word、Markdown、HTML；记忆可见可编辑；用户或项目提示词覆盖默认教学提示词；云端定时发送提醒与预备邮件；反馈驱动的候选策略经验证与人工确认后启用。

桌面负责对话、文件、诊断、复测、记忆、提示词和导出。本地项目目录保存学习内容。用户自行配置模型服务。共享云端只保存必要提醒信息并发送邮件，电脑关机时已同步任务继续执行。首版在电脑完成复测，手机接收邮件。

## 二、功能需求

### F01 项目与对话

创建、重命名、归档项目并选择目录；项目资料和学习记录隔离；新建、搜索、筛选及继续对话；自动保存并恢复已发送消息和诊断进度。

### F02 诊断与盲点

输入主题后明确本轮范围。默认5个主问题，每个最多2次追问，可提前结束。支持回答、跳过、不会和提示，区分独立与辅助回答。盲点记录原问题、原回答、追问、依据、状态和建议；证据不足为待确认，支持纠错。状态为待确认、待补齐、待复测、复测通过并继续巩固。同一知识点连续追踪。

### F03 Markdown 总结

诊断和复测结束自动生成真实 .md 文件；支持手动生成阶段总结。包含目标、范围、知识点、盲点证据、讲解、复测及来源。可预览、编辑、搜索、打开目录，与来源对话关联。重新生成保留旧版本及手动修改。

### F04 文件工具

提供 list_files、read_file、search_files、write_file。真实路径在授权范围内；写前比较版本；展示调用记录、状态及错误；成功反馈文件位置。新总结自动保存，候选记忆和策略按确认流程保存。

### F05 导出

支持整段、选定消息和总结导出。Markdown 保留结构，HTML 单文件可读，PDF 中文与分页正常且可选文本，Word 为真实可编辑 .docx。选择位置和文件名，显示进度、取消、失败和打开操作。本地执行，不依赖模型。验证长代码、中文、表格和长对话。

### F06 记忆

区分用户与项目记忆，以 Markdown 为内容源，支持查看、编辑、新增、删除和暂停。候选记忆提供来源、时间，确认后保存；明确“记住”指令可直接保存。掌握状态依据诊断与复测维护并支持纠正。

### F07 提示词

用户级与项目级 Markdown 提示词可编辑、打开目录、恢复默认。非空项目提示词优先，否则用户提示词，否则默认模板，不自动拼接两级模板；展示生效内容，下一次请求生效并记录版本。权限边界由程序执行。

### F08 定时任务

一次性、每日、每周；默认 Asia/Shanghai，可修改。表单或自然语言草稿，保存前预览时间、规则、本人邮箱、正文。支持修改、暂停、恢复、删除。同步成功才显示云端启用，离线草稿为待同步。应用运行时桌面通知，重启同步历史。开发者统一部署云服务和发信渠道，用户验证邮箱。学习提醒每日摘要，无任务不发；独立邮件按规则执行。每次到期唯一记录，失败最多重试3次，间隔1、5、15分钟；状态区分已提交渠道、失败、待重试，不能凭 SMTP 接受宣称送达。

### F09 自进化

收集经核实的纠错、歧义和复测反馈，总结候选题目模板、诊断规则、讲解策略，展示依据、适用范围、版本和验证记录。开发与验收样例分开，检查目标改善和已有样例退步。人工启用，限定项目，支持停用与回退，保留实际结果。

### F10 配置及可靠性

每人配置接口、模型名和密钥，连接测试；密钥用系统安全存储，界面掩码。展示请求、写文件、导出、同步和发送状态。任务可取消，失败保留数据。外部文件编辑可重新加载，冲突保留版本。示例与模拟明确标识。

## 三、数据与运行约束

学习内容本地保存；模型仅获取当前任务所需上下文；密钥本地加密；云端仅保存任务元数据、本人收件人、预备正文和执行记录，SMTP 凭据服务端管理。Markdown 是可编辑内容源。文件工具检查解析后的路径。完成、取消和修改复习后更新云任务。无网络仍可读写本地文件、历史及导出。Windows 首版；移动复测及云 AI 后续扩展。

## 四、验收标准

|编号|通过条件|
|---|---|
|A01|完成主题诊断，追问并生成有证据的报告|
|A02|重启恢复会话和进度|
|A03|自动生成真实 Markdown 并关联对话|
|A04|重新生成保留手动内容和版本|
|A05|四种格式可打开，中文代码表格可读，PDF可选、Word可编辑|
|A06|记忆界面和文件一致，后续任务使用更新|
|A07|提示词按优先级生效，可查看版本和恢复|
|A08|电脑关机后已同步邮件由云端执行，重启可查|
|A09|离线任务待同步，成功后才标记启用|
|A10|修改或暂停更新云安排且可追踪|
|A11|策略展示证据、验证和人工确认，后续采用启用版|
|A12|策略可回退并保留历史|
|A13|越界操作被拒绝，授权内正常|
|A14|失败明确、数据保留、不将失败显示为完成|

自进化至少20条人工核对样例，分开发和验收，使用同一模型配置比较结果、追问与耗时，如实展示。

## 五、交付

阶段一：本地学习、文件、总结、记忆和提示词。阶段二：四种导出、邮箱绑定、云调度、桌面提醒和记录。阶段三：策略候选、验证、人工启用、回退、Windows 打包及演示。最终交付安装包、云服务、示例、说明、配置说明、验收记录和演化演示。
